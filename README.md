# Silk Spoon Restaurant — React Site

Light multi-page recreation of [silkspoon.com.bd](https://silkspoon.com.bd) design system.

## Design tokens

| Token | Value |
|-------|-------|
| Primary | `#3B5844` |
| Secondary | `#68a050` |
| Heading | `#03200C` |
| Silk gold | `#b99942` |
| Soft bg | `#F3FDE8` |
| Dark | `#000000` |
| Fonts | Manrope, Bricolage Grotesque |
| Max width | 1140px |
| Button radius | 48px (pill), 7px (primary) |

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/menu` | Food Menu |
| `/gallery` | Image Gallery |
| `/videos` | Video Gallery |
| `/contact` | Contact |
| `/reservation` | Table Reservation |

## Run (Windows / Mac / Linux)

```bash
cd silkspoon-react
npm install
npm run dev
```

Open http://localhost:5173
